# Lab 7 — Обобщённые контейнеры, бинарное дерево поиска и паттерн «Итератор»

## Описание

В данной работе реализован набор собственных шаблонных контейнеров на языке C++:

- `Vector<T>` — динамический массив;
- `Stack<T>` — стек на основе односвязного списка;
- `Tree<T>` — бинарное дерево поиска.

Все контейнеры объединены общим абстрактным интерфейсом `Collection<T>`, а обход элементов выполняется через абстрактный интерфейс `Iterator<T>`. Для дерева реализованы два варианта обхода: в глубину (`DFSIterator`) и в ширину (`BFSIterator`).

Проект демонстрирует применение:

- шаблонного программирования;
- наследования и полиморфизма;
- абстрактных классов;
- динамического управления памятью;
- паттерна проектирования «Итератор».

## Структура проекта

- `Iterator.h` — абстрактный интерфейс итератора;
- `Collection.h` — абстрактный интерфейс коллекции;
- `Vector.h` — реализация шаблонного динамического массива;
- `Stack.h` — реализация шаблонного стека;
- `Tree.h` — реализация шаблонного бинарного дерева поиска;
- `utils.h` — перегрузка оператора вывода для итераторов;
- `main.cpp` — тестирование всех реализованных контейнеров.

## Реализованные возможности

### `Vector<T>`

- добавление элемента в конец;
- поиск элемента;
- удаление первого найденного элемента;
- полная очистка;
- автоматическое увеличение внутреннего массива;
- обход элементов через `VectorIterator`.

### `Stack<T>`

- добавление элемента на вершину стека;
- поиск элемента;
- удаление первого найденного элемента;
- полная очистка;
- обход элементов через `StackIterator`.

### `Tree<T>`

- вставка элемента по правилам бинарного дерева поиска;
- поиск элемента;
- удаление узла;
- полная очистка дерева;
- обход дерева в глубину (`DFS in-order`);
- обход дерева в ширину (`BFS level-order`).

## Ограничения на тип `T`

Для корректной работы шаблонных классов тип `T` должен удовлетворять следующим требованиям:

### Для `Vector<T>`

- поддержка оператора `==`;
- поддержка оператора присваивания `=`;
- наличие конструктора по умолчанию.

### Для `Stack<T>`

- поддержка оператора `==`;
- возможность копирования значения в узел списка.

### Для `Tree<T>`

- поддержка операторов `<`, `>`, `==`;
- поддержка оператора присваивания `=`.

## Тестирование

В файле `main.cpp` выполняется тестирование контейнеров на следующих типах данных:

- `Vector<double>`;
- `Vector<std::string>`;
- `Stack<int>`;
- `Tree<double>`;
- `Tree<std::string>`.

Проверяются операции добавления, поиска, удаления, полной очистки и обхода элементов.

## Сборка и запуск

Проект ориентирован на сборку в **Microsoft Visual Studio**.

### Шаги запуска:

1. Открыть решение `lab_7.slnx` или проект `lab_7.vcxproj` в Visual Studio.
2. Выполнить сборку проекта.
3. Запустить `main.cpp` как точку входа.
4. Просмотреть результаты тестирования в консольном окне.

## Пример демонстрируемых результатов

После запуска программа выводит:

- содержимое контейнеров;
- результаты поиска элементов;
- состояние после удаления элемента;
- состояние после полной очистки;
- результаты DFS- и BFS-обхода дерева.
